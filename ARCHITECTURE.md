# Архитектура первой версии

Приложение состоит из расширения GNOME Shell и отдельного пользовательского
помощника `clipboard-typer-helper`.

* `src/gnome44` — legacy-сборка для GNOME Shell 44 (`imports.*`).
* `src/gnome46` — ESM-сборка для GNOME Shell 45/46.
* `src/helper/clipboard-typer-helper` — читает UTF-8 только из stdin и запускает
  `xdotool` массивом аргументов, без shell и `eval`.
* GSettings хранит настройки и, если это разрешено пользователем, не более 20
  уникальных строк истории в пользовательской базе dconf.

Расширение опрашивает текстовый `CLIPBOARD`, дедуплицирует историю, строит меню
панели и регистрирует глобальные сочетания клавиш GNOME Shell. При наборе меню
закрывается, прежнее окно получает фокус, после настраиваемой паузы helper
передаёт ввод активному X11-окну. Остановка посылает helper-у SIGTERM; helper
завершает дочерний `xdotool` и не допускает продолжения ввода.

Wayland намеренно не поддерживается в первой версии: `xdotool` использует XTEST,
а ввод через XWayland не является надёжным механизмом для Wayland-приложений.
